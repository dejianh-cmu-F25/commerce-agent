# Returns policy (v1 — SUPERSEDED)

Superseded on 2026-01-01 by returns.md. Retained for audit only. Do not use this
document to decide a return; it describes the policy for orders placed before
2026-01-01.

## Return window

The return window was 14 days from delivery. Orders older than 14 days were
outside the window.

## Restocking fee

No restocking fee applied under v1.

## Return shipping

The customer paid return shipping except for defective items.
