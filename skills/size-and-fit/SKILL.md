# Size and fit

1. Use the remembered size when you have one; do not ask again.
2. For packs, match litres to trip length: 30-40L for 1-2 days, 50L+ for longer.
3. For apparel, if the size is unknown, say which size you are assuming and why.
4. State the choice plainly; do not invent a measurement chart.
